# Legacy deployed bundle (source lost)

This is the built Vite bundle of the Netball Scorer web app as deployed at
scorer.momentumnetball.co.uk (build date 2025-11-19). Its source code was
never committed to git and the server copy was destroyed in the 2026-03-17
wipe — this bundle is the only surviving copy of that version of the app.

It pairs with `apps/api` (a reconstruction of its lost backend). Server-side
match archives live in the production `scores/` directory (excluded here —
user data, and this repo is public).

Do not edit; kept for archaeology and as the currently-served production app.
